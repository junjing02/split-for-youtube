# Split for YouTube

Watch and read at the same time. A Chrome extension that turns the YouTube watch page into a clean two-column layout — video on the left, everything else on the right.

## Why

YouTube's description, recommendations, and comments all compete with the video for space, and there's no way to resize any of it. Split Layout fixes that: the video gets its own column, and description, recommendations, and comments stack in a resizable pane next to it.

## Features

- **Video-first by default** — every video loads with the player at its largest possible size; the side pane takes whatever's left.
- **Resizable, your way** — drag the divider between video and side pane, or between recommendations and comments, to whatever split you want.
- **Collapsible sections** — description, recommendations, and comments each collapse to a single header with one click.
- **Live streams supported** — recommendations automatically become live chat while a stream is live.
- **Stays out of the way** — theater mode, shorts, and smaller windows all fall back to YouTube's normal layout untouched.

## Install

Not on the Chrome Web Store — load it as an unpacked extension:

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome (or any Chromium-based browser).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
5. Open any YouTube video.

## Requirements

Works on a spacious, landscape-oriented window — full screen or close to it. On a narrow or short window, YouTube's normal layout is left untouched.
