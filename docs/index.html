Why use it

The video never scrolls away.

Browse recommendations or read comments while the video keeps playing in full view.

Always in view

The video gets its own column. Scrolling comments or recommendations never carries it off-screen.

Drag to resize

Move either divider to split the space however you like — between video and side pane, or recommendations and comments.

Install

Up and running in a minute.

Not on the Chrome Web Store yet — load it as an unpacked extension.

  1. Download the ZIP and unzip it, or clone the repository.
  2. Open chrome://extensions in Chrome or any Chromium-based browser.
  3. Turn on Developer mode in the top right.
  4. Click Load unpacked and select the unzipped folder.
  5. Open any YouTube video.

Works best in a large, landscape window. In smaller windows, YouTube keeps its normal layout.
