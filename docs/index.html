Why use it

YouTube's description, recommendations, and comments all compete with the video for space, and none of it is resizable. Split for YouTube fixes that.

Video-first by default

Every video loads with the player at its largest possible size — the side pane takes whatever's left.

Resizable, your way

Drag the divider between video and side pane, or between recommendations and comments, to whatever split you want.

Collapsible sections

Description, recommendations, and comments each collapse to a single header with one click.

Live streams supported

Recommendations automatically become live chat while a stream is live.

Stays out of the way

Theater mode, shorts, and smaller windows all fall back to YouTube's normal layout, untouched.

Install

Not on the Chrome Web Store yet — load it as an unpacked extension:

  1. Download or clone the repository.
  2. Open chrome://extensions in Chrome (or any Chromium-based browser).
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the project folder.
  5. Open any YouTube video.

Works best on a spacious, landscape-oriented window — full screen or close to it.
